Crop Water Stress Prediction

Using Kernel-Based Classification (Non-linear SVM) to monitor crop health

About The Project

This project implements a Machine Learning solution to predict whether a crop plot is experiencing water stress. It leverages a Support Vector Machine (SVM) with a Radial Basis Function (RBF) kernel to capture non-linear relationships between various environmental metrics.

Features Used for Prediction

  • 💧 Soil Moisture: Water content in the soil.
  • 🌡️ Temperature: Ambient or soil temperature.
  • ☁️ Humidity: Moisture level in the air.
  • 🌱 Vegetation Index: Remote sensing metrics (e.g., NDVI) indicating plant health.

Data Pipeline

The pipeline ingests datasets directly from Kaggle. It preprocesses the features, handles missing values, scales the numerical inputs, and fits the Kernel SVM model to output a water stress classification.

Usage

To run the model locally, clone the repository and execute:

pip install -r requirements.txt
python analyze.py
